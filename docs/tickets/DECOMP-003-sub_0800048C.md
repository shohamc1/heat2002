# DECOMP-003: `sub_0800048C` — read key input

**Status:** done (commit 4e4781b)
**Target:** `sub_0800048C` @ `0x0800048C`, 17 insns, 40 callers, leaf, no `bl`

## Target asm

```asm
sub_0800048C:
	push {r4, lr}
	ldr r0, _080004AC @ =0x04000130      @ REG_KEYINPUT
	ldrh r1, [r0, #0x00]
	mvns r1, r1
	lsls r1, r1, #0x10
	lsrs r1, r1, #0x10                   @ u16 keys = ~REG_KEYINPUT
	ldr r4, _080004B0 @ =0x020005CC      @ gKeysPressed
	ldr r3, _080004B4 @ =0x020005C8      @ gKeysHeld
	ldrh r2, [r3, #0x00]
	adds r0, r1, #0x0
	bics r0, r2
	strh r0, [r4, #0x00]                 @ pressed = keys & ~held
	strh r1, [r3, #0x00]                 @ held = keys
	pop {r4}
	pop {r0}
	bx r0
```

## Steps

1. `symbols.ld`: add `gKeysHeld = 0x020005C8;` and `gKeysPressed = 0x020005CC;`
   (names are yours; keep the `0x0200xxxx` EWRAM addresses exact).
2. `src/sub_0800048C.c`: `extern u16 gKeysHeld, gKeysPressed;` then a void
   function that reads `*(volatile u16 *)0x04000130`, inverts, and stores.
   Try one local `u16 keys` first; the `push {r4, lr}` says the compiler
   wanted a callee-saved register, which usually means two live globals'
   addresses plus one temp.
3. `python3 scripts/match.py sub_0800048C` until MATCH.
4. Extract: the block is followed by `_080004B8:` (16 bytes of ARM code as
   `.byte`) and `_080004C8:` (more data) -- KEEP those; they start the new
   fragment `asm/rom_080004B8.s`. Add the object to `ldscript.ld` between
   `rom.o` and the new fragment.
5. `make check` -> MATCH, `progress.py`, commit.

## Risks

- `mvns` then `lsls/lsrs`: the invert is done in 32 bits then narrowed --
  `keys = ~REG_KEYINPUT` with `u16 keys` should produce exactly this.
- Order of the two stores matters and is fixed by the C statement order.
- The `.4byte` for `REG_KEYINPUT` must come out of the compiler as a literal
  (it will; it is a constant address cast, not a symbol).
